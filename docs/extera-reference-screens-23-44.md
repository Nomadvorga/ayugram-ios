# exteraGram / AyuGram: опись референсов 23–44

Дата: 2026-11-25. Источник: **каждое** изображение `photo_N_2026-11-25_21-26-04.jpg`, N = 23…44, из `C:\Users\PC\Downloads\Telegram Desktop`. Все 22 файла открыты инструментом чтения изображений и прочитаны визуально. Изображения не изменялись и не копировались в репозиторий.

Задача этой описи — зафиксировать видимый интерфейс и сопоставить его с текущим исходным кодом. Это **статическая сверка, не подтверждение runtime-, визуального или анимационного паритета**. Значения на скриншотах — состояние конкретного Android-устройства, а не доказанные значения по умолчанию. Поведение за пределами показанного кадра не выводится из изображения. Многоточия ниже сохранены там, где текст обрезан самим интерфейсом; скрытое продолжение не выдумывается.

Прочитаны корневые `AGENTS.md` и `CLAUDE.md` AyuGram iOS. Код приложения только читался. Гайд Sigilforge из Downloads относится к другому проекту; его требования по журналам и файлам не применялись. Плагины исключены из переноса по условию задачи, но их присутствие в исходных кадрах зафиксировано для точности.

## Общий визуальный язык кадров

- Вертикальные Android-кадры, чёрный фон, тёмно-серые большие карточки с сильно скруглёнными внешними углами; белые основные подписи, серые описания, сине-сиреневый акцент.
- Строки внутри карточки разделены тонкими тёмными линиями, обычно начиная от текстовой колонки. Заголовки секций вынесены над карточками и окрашены акцентом.
- Вверху системная строка состояния: время 21:16–21:18, батарея 27%, системные иконки. Внизу Android gesture bar. Эти системные элементы не являются настройками приложения.
- Кнопка возврата — большая отдельная круглая кнопка слева. На экранах навигации и чатов справа круглая кнопка с закольцованной стрелкой (визуально reset); последствия нажатия кадрами не показаны.
- При прокрутке заголовок остаётся сверху, а контент уходит под затемняющую область за ним. По статичным кадрам нельзя определить длительность и кривую анимации.
- Выключенный switch — серый контур/трек с бегунком слева; включённый — синий трек с бегунком справа. Выбранные radio и карточки выделены синим. Бейдж `NEW` — маленькая синяя скруглённая плашка с белым текстом.

## Платформенные исключения и неопределённости

- **Плагины:** строка присутствует на 27–29, исключена из переноса явным требованием пользователя. Не реализовывать её как нерабочую заглушку ради совпадения списка.
- **AOSP:** описание на 25/27 прямо относится к системной Android-анимации. Точный AOSP-модуль для iOS неприменим; нативный transition и Spring требуют отдельного согласованного соответствия и проверки кадров. Сам selector анимации не следует молча считать реализованным.
- **Закрыть приложение:** Android-действие на 29 не имеет обычного пользовательского iOS-эквивалента. Его исключение нужно фиксировать, не имитировать crash/exit. Остальные menu items не объявлены несовместимыми только из-за нахождения в том же списке.
- **Material Design 3 / системные шрифты и эмодзи:** Android-компоненты не переносятся как модули iOS. На этом кадре не раскрыт состав 3/8, поэтому объём нативных аналогов неизвестен. Отдельно остаются проверяемыми per-chat themes, section spacing, divider type и формы preview.
- **Иконка приложения:** альтернативные иконки iOS должны быть заранее включены в bundle и переключаться разрешённым способом. Само наличие Android-вариантов на 24 не доказывает ни наличие соответствующих iOS assets, ни невозможность их переноса.
- **Планшетный режим:** кадр задаёт UX auto/on/off, но не показывает фактический tablet layout. Не объявлять несовместимым автоматически; требуется определить нативное поведение iPhone/iPad.
- **Не показано:** варианты `Анимация переходов`, `Тип разделителей`, `Система мер`, `Валюта по умолчанию`; внутренности MD3 3/8; действия add icon set; выбор сервиса/роли/истории AI; скрытые подразделы справки валют/единиц/часовых поясов. Они не специфицированы догадками.
