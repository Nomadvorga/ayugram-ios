# AyuGram for iOS

Неофициальный клиент Telegram для iOS с функциями [AyuGram](https://github.com/AyuGram).

## Откуда взялся код

- **Основа** — [Swiftgram](https://github.com/Swiftgram/Telegram-iOS), форк официального [Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS). От него взяты сборка, исходники Telegram и инфраструктура настроек.
- **Функции AyuGram написаны с нуля** под iOS по поведению AyuGram для Android: режим призрака, сохранение удалённых сообщений, история правок, исключения по чатам и остальное ниже.
- **От самого Swiftgram почти ничего не осталось.** Swiftgram Pro, экспорт сообщений в JSON и ряд его функций удалены; оставшиеся мелкие настройки интерфейса собраны во вкладке «exteraGram».

## Функции

**Режим призрака** — главный переключатель и пункты под ним:
- не отправлять отметки о прочтении сообщений и историй;
- не отправлять «онлайн» и «печатает» (речь в групповых звонках и emoji-взаимодействия не трогаются);
- автоматический «офлайн» и «онлайн на 0,2 с при отправке»;
- свой «последний визит» в собственном профиле;
- «Читать при действиях», отложенная отправка, отправка без звука;
- исключения по чатам: всегда/никогда читать, всегда/никогда «печатать».

**Шпион:**
- сохранение удалённых сообщений с меткой (стиль и цвет настраиваются) и полупрозрачностью;
- история правок с отдельным экраном;
- дата удаления и дата прочтения в меню сообщения;
- исключения сохранения по чатам, сохранение в чатах с ботами;
- одноразовые фото, видео и голосовые можно смотреть сколько угодно;
- последние известные телефон, юзернейм и заметка остаются в профиле, даже если человек их скрыл.

**Другое:** отключение рекламы, запоминание камеры для кружков, исправления ночной темы на iOS 27.

## Сборка

IPA собирается в GitHub Actions (`.github/workflows/build-ipa.yml`) без подписи, с кэшем Bazel. Готовый файл подписывается и ставится через Sideloadly или AltStore. Для входа в аккаунт нужны свои `API_ID` и `API_HASH` с [my.telegram.org](https://my.telegram.org) в секретах репозитория.
