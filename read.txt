## Design already decided
- New compatibility is written in Python wherever it is pure logic or can be composed from what the host
  already declares, so it is testable: provider modules in Python/_ayu_javalib/ exposing
  `CLASSES = {"java.util.ArrayList": cls, ...}`. A class the Swift host declares wins over a local one.
  A local class that needs a host operation lists it in `__ayu_requires__` and is advertised to preflight
  only when the host declares that operation, so preflight never claims support that is not there.
- Swift/ObjC edits stay small, follow existing patterns (the target builds with -warnings-as-errors), are
  syntax-checked, and are reported as "not compiled".
- No fake success: unimplemented APIs raise UnsupportedAPI.
